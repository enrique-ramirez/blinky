# Words and phrases that make prose read like an assistant rather than a person.
#
# Three kinds of line:
#
#   !phrase    a literal substring, checked mechanically, case-insensitive
#   ~regex     a Python regular expression, checked mechanically
#   phrase     judgement, applied by the review agents and never by the hook
#
# The mechanical set is deliberately small. It holds only phrases with no
# innocent use in a source tree. Ordinary English stays on the judgement list,
# because a word like "power" or "fast" is honest in an identifier, a fixture,
# a test name or a sentence somebody meant.
#
# RFC 2119 keywords are not register hits. Documentation uses MUST, SHOULD and
# MAY for obligations on purpose.
#
# A repository may add its own lines in `.claude/register.local.txt`, which is
# read after this file.
